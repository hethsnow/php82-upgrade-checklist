# PHP 5.x / 7.x 升级到 PHP 8.2 检查清单

用于旧 PHP 系统升级后的兼容性排查：快速定位异常函数、已移除或弃用的用法、类型与方法签名变化，帮助修复错误并恢复业务正常运行。

## 为什么整理这份清单

在应对 PHP WebShell 风险、进行安全加固或升级运行环境时，旧系统可能暴露此前没有触发的兼容问题：页面白屏、接口响应异常、旧函数不可用、方法签名不兼容，或原先忽略的 Warning / Deprecated 被错误处理器转成异常。

本项目将 PHP 版本差异整理为可以逐项核对的清单，给出搜索对象、变化版本、处理要点及验证方法，减少逐个搜索错误信息的时间，帮助开发和运维人员尽快恢复正常运行。

WebShell 风险需要专门的安全排查和处置；本清单聚焦 PHP 升级兼容性，不能替代漏洞修复或安全验收，也不意味着仅升级 PHP 就能消除安全风险。

## 清单包含什么

| 范围 | 内容 |
| --- | --- |
| 语法与移除项 | 旧下标语法、字符串插值、运算符优先级、移除函数与扩展 |
| 弃用与类型 | null 传参、隐式转换、默认值、字符串及数组行为 |
| 类与调用契约 | 方法签名、继承、魔术方法、内置接口实现、回调与序列化 |
| 错误与扩展 | Warning / Exception / Error 差异、资源转对象、扩展 API 与协议默认值 |
| 配置与代码规范 | INI 变化、最低语法版本、强制兼容规则与可选编码风格的区别 |
| 查修与验证 | 只读候选扫描、最小复现、双版本对照、完整响应与多级日志、隔离回归 |

各条目使用稳定编号，可填写“通过 / 待修 / 不适用”。同一规则合并收录，避免把不同项目中的同类错误重复列为新问题。

## 快速使用

1. 记录原始 PHP 精确版本、目标版本，以及 Web / CLI 实际使用的解释器、配置和扩展。
2. 在 [完整清单](CHECKLIST.md) 中先检查语法错误和已移除项，再检查类型、参数、方法签名及默认行为。
3. 对每个命中保留最小复现，按原有输入与输出契约修复，在实际支持的各 PHP 版本验证。搜索命中不等于错误，不要执行全局机械替换。
4. 复查原始响应和新增日志，包括被捕获后写入 info / debug 的异常；涉及外部 I/O 时使用隔离替身，验证完整调用链。
5. 使用以下格式记录结果：

```text
编号｜旧版本｜目标版本｜命中位置/调用｜状态｜修复方式｜最小验证结果
```

清单中的扫描命令用于寻找候选项，不会自动改代码。示例中的版本范围应按项目实际支持区间填写。

## 适用边界

- 收录由 PHP 语言、内置函数、内置扩展或运行时版本变化引起的通用兼容规则。
- 项目、框架或第三方库自定义函数的业务逻辑与自身实现缺陷不单列。
- PHP 规定的魔术方法、内置接口方法，以及普遍适用的参数、继承和回调规则仍在范围内。
- PHP 8.2 是这份文档的固定目标，不表示它始终是 PHP 的最新版本；迁移到其他版本时应另行核对对应官方迁移文档。
- 不包含具体业务案例、生产源码、服务器信息、凭据、用户数据或一般服务器故障记录。
